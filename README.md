# KLSE 三倍放量提醒

只做一件事：**今日累计成交量 ÷ 上一有成交交易日全天量 ≥ 3，就发送文字提醒。** 刚好3倍也达标。

不设最低成交股数、成交额、涨跌幅、均线或形态条件，不排名，不限制前三只。不生成图片，不提供买点、支撑或投资分析。

```text
📊 三倍放量提醒 · 2026-10-21

MAYBANK (1155) · 昨日 3.25 倍
今日 3,250,000 股｜昨日 1,000,000 股
```

- 开市期间每5分钟扫描 TradingView 马来西亚股票/DR池，Yahoo Finance提供完整交易日成交量。只需一个有效的前一交易日数据，不要求20日或OHLC。
- 同一只股票每个交易日提醒一次，去重保存在SQLite，重启后不重复。所有达标股票都会记录；大量股票按Telegram文字长度分批发送，不按排名截断。
- 网页提供三倍以上列表、全部股票和最近200条通知记录。Telegram未配置或关闭时，仍保存网页记录。
- Telegram发送失败保留原文字重试；跨日或超过15分钟的旧提醒停止发送。发送成功但响应丢失时，重试仍可能重复，不保证恰好一次送达。
- `/top`（或 `/screen`）查看达标股票，`/stock MAYBANK` 或 `/stock 1155` 查询成交量。只响应配置的Telegram聊天，不再提供AI对话或策略参数命令。

## 数据口径

成交量单位为股。盘中累计量直接与上一有成交交易日的全天量比较，不外推全天量。缺少有效昨日量、昨日量为零、资料过期或分页不完整时，等资料补齐再判断，不把缺失当作零。

常规时段为MYT 09:00–12:30、14:30–17:00，休市日期由管理员维护，半日安排需单独处理。免费行情可能延迟，抓取时间不等于交易所实时行情时间，覆盖范围取决于上游股票池。

旧数据库可直接升级：保留既有行情与历史记录，取消未发送的旧策略/图片通知。新的三倍量通知使用独立的每日去重记录；旧筛选配置不再参与判断。

## 运行

需要Node.js 24或更新版本（内置 `node:sqlite`）。

```sh
npm ci
cp .env.example .env
# 编辑 .env，填写随机 ADMIN_TOKEN 和可选的 Telegram 凭据
npm test
npm run build
npm start
```

打开 `http://localhost:8080`。开发时另开终端运行 `npm run dev`，Vite将 `/api` 代理到8080。

| 环境变量             | 用途                                        |
| -------------------- | ------------------------------------------- |
| `ADMIN_TOKEN`        | 修改设置和手动刷新所需的管理员令牌          |
| `TELEGRAM_BOT_TOKEN` | 可选，Telegram机器人令牌                    |
| `TELEGRAM_CHAT_ID`   | 可选，接收通知的聊天ID                      |
| `DATA_DIR`           | SQLite和config.json的持久目录，默认项目目录 |
| `PORT`               | 默认8080                                    |

网页设置只保留Telegram开关、凭据和休市日期。凭据不在公开接口回显，管理员令牌仅在设置窗口中暂存。环境变量优先于config.json。

Render使用现有 `render.yaml`，构建时运行测试与Vite构建，数据库保存在 `/var/data`。

## 验证

```sh
npm test
npm run build
npm run format:check
npm run preview:fixture
```

离线预览位于 `http://localhost:8091`，使用独立临时数据库、明确标注的示例股票且禁用外网通知。管理员测试令牌为 `preview-only-token`；可用 `PREVIEW_DATE=2026-10-21` 固定预览日期。

测试覆盖三倍边界、小成交量、单日历史、全部匹配、每日持久去重、纯文字发送、失败重试、旧库升级、完整市场分页、日量补齐、权限和SSE。

## 代码

- `server.js`：市场扫描、SQLite、通知队列、Telegram和HTTP。
- `lib/volume.js`：交易日期、三倍量判断和简短通知文字。
- `lib/settings.js`、`lib/security.js`：设置校验和管理权限。
- `src/App.jsx`、`src/styles.css`：成交量列表与通知设置。
