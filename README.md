# KLSE Volume Tracker — 马来西亚股票成交量异动追踪

每 N 分钟抓取自选股的盘中成交量（Yahoo Finance 免费接口，无需 key），当「当前时段成交量」达到「上一时段成交量」的 n% 时提醒你。纯 Python 标准库，零第三方依赖。

## 功能

- **盘中成交量追踪**：5 分钟粒度 candle，默认每 10 分钟轮询一次
- **可调对比时段**：10 分钟 / 30 分钟 / 1 小时 / 2 小时 / 5 小时 / 1 天（今日 vs 昨日）
- **异动提醒**：当前时段量 ≥ 上一时段量的 n%（放量）或 ≤ n%（缩量）时触发
- **网页实时展示**：现价、当前/上一时段成交量、对比比率、告警记录
- **提醒方式**：网页内通知 + 告警列表；可选 Telegram 推送

## 运行

```bash
cd volume-tracker
python server.py
```

打开 http://localhost:8080

要求 Python 3.8+（无需 `pip install`，只用标准库）。端口可用环境变量 `PORT` 修改（默认 8080）。

## 配置

首次运行自动生成 `config.json`，也可在网页「设置」面板修改：

| 字段 | 说明 | 默认 |
|------|------|------|
| `window` | 对比时段 | `1h` |
| `threshold_percent` | 提醒阈值 %（当前/上一时段） | `200` |
| `direction` | `surge` 放量 / `drop` 缩量 | `surge` |
| `min_previous_volume` | 上一时段量低于此值不提醒（过滤冷门股） | `100000` |
| `cooldown_minutes` | 同一只股票两次提醒最短间隔 | `30` |
| `poll_interval_minutes` | 轮询间隔 | `10` |
| `telegram_bot_token` / `telegram_chat_id` | Telegram 推送（可选） | 空 |

`watchlist` 是自选股列表（`code` 纯数字，后端自动加 `.KL` 后缀），可在网页直接添加/删除，或手动编辑 JSON。

## 数据

- `data.db` — SQLite（5 分钟 candle、每日量、告警记录、告警状态）
- `server.log` — 运行日志

## 部署（7×24 运行）

本机前台 `python server.py` 只在你开着终端时运行。要长期运行：

- **本机后台**：`pythonw server.py`（Windows 无窗口）或任务计划程序开机启动
- **云主机**：Render / Railway / Fly.io 免费档都支持 Python Web 服务，把仓库推上去即可（无需数据库服务，SQLite 用持久磁盘）

注意：Yahoo 是**非官方**接口，免费、无需 key，但请控制自选股数量（几十到几百只）与轮询频率，避免被限流。如需「全部 1082 只马股 + 盘中 + 批量」，需改用付费数据源（如 EODHD 付费套餐）。

## 提醒语义

- 滚动时段（10m~5h）：按「交易 candle」滚动（5 分钟一根，1 小时=12 根），`当前 = 最近 N 根 candle 量之和`，`上一 = 再往前 N 根`，**自动跳过午休(12:30–14:30)与隔夜**，所以「上一时段」= 上一段有交易的时段
- 1 天模式：`当前 = 今日累计量`，`上一 = 前一交易日全天量`
- 每只股票在「跌破阈值 → 再次突破」之间只提醒一次（配合冷却时间防抖）
